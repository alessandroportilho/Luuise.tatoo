# 🖤 luuise.ink | Tattoo Studio Portfolio

Um site de portfólio moderno, elegante e totalmente responsivo desenvolvido para o estúdio de tatuagem **luuise.ink**. O projeto foi criado com uma estética *Dark Mode* para destacar as fotografias e artes, proporcionando uma experiência imersiva ao usuário.

🌐 **Acesse o site ao vivo:** [luuisetatoo.github.io]

## 🎯 Objetivo do Projeto
Fornecer uma plataforma digital rápida e visualmente atraente para exibição de trabalhos (Blackwork, Fineline e Realismo), além de facilitar o contato e agendamento de sessões através de integrações diretas com WhatsApp e Instagram.

## ✨ Funcionalidades (Features)
- **Design Moderno (Dark Mode):** Interface imersiva que destaca as cores originais das tatuagens.
- **Totalmente Responsivo:** Layout fluido que se adapta perfeitamente a smartphones, tablets e desktops.
- **Animações Fluídas:** Efeitos de *reveal* ao rolar a página (scroll) e interações magnéticas na galeria.
- **Call to Action (CTA):** Botões de contato direto para redes sociais e WhatsApp, focados em conversão.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estrutura semântica.
- **Tailwind CSS:** Para estilização rápida, moderna e responsiva via CDN.
- **JavaScript (Vanilla):** Para o funcionamento do menu mobile e as animações de scroll (Intersection Observer).
- **FontAwesome:** Para os ícones de redes sociais e UI.
- **Google Fonts:** Tipografia (Inter e Playfair Display).
